Placement Prediction ML Project

This is one of my Machine Learning projects where I worked on predicting student placement outcomes using student-related data.

I built this project to understand how Machine Learning can be used to solve a real-world problem. Along with model development, I also explored how to connect a model with a backend and a simple web application.

Technologies Used

- Python
- NumPy and Pandas
- Scikit-learn
- PyTorch
- FastAPI
- Streamlit
- Docker

Project Structure

- "backend.py" – Backend API for handling prediction requests.
- "frontend.py" – Streamlit application.
- "config.py" – Configuration settings.
- "ds-project-1.ipynb" – Jupyter Notebook containing the project work.
- "college_student_placement_dataset.csv" – Dataset used in the project.
- "Dockerfile" – Docker configuration.
- "requirements.txt" – Python dependencies.

What I Worked On

- Explored and worked with the student placement dataset.
- Practiced data preprocessing and feature analysis.
- Worked with concepts such as PCA, SVD and Maximum Likelihood Estimation.
- Developed the machine learning workflow.
- Used FastAPI to create the backend.
- Used Streamlit to build the frontend.
- Explored Docker for running the application.

Running the Project

Clone the repository:

git clone https://github.com/gagangoswami0512/placement-prediction-ml.git
cd placement-prediction-ml

Create and activate a virtual environment:

python -m venv .venv

Install the dependencies:

pip install -r requirements.txt

Run the backend and frontend using their respective application commands.
